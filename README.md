# 청라 레이크포레 — 살아있는 사업계획서

> 사업장·시행사·시공사·재무 자료는 **100% 교육용 합성 데이터**입니다. 시장 자료만 공공데이터포털의 실제 공개자료입니다.

스크롤을 따라 카메라가 단지(매스 스터디)를 비행하고, 밤이 되면 **창 하나 = 한 세대**로 분양률만큼 불이 켜집니다. 그 아래로 소요자금표에서 계산한 입력값, 공공데이터로 매일 갱신되는 분양 가정, 두 손익분기와 2축 민감도, 의견이 이어집니다.

## 실행

```bash
npm install
cp .env.example .env.local   # DATA_GO_KR_SERVICE_KEY 또는 DATA_GO_KR_API_KEY 입력 (서버 전용)
npm run dev
npm test                     # 25개 단언: 입력값·손익분기·파서·보안
npm run build                # 키 없이도 통과 — 빌드 시 API 미호출
```

배포: Vercel 프로젝트 환경변수 `DATA_GO_KR_SERVICE_KEY` 또는 zipcatch와 같은 `DATA_GO_KR_API_KEY` 설정 → 재배포. `vercel.json`은 서울 리전(`icn1`).

## ① 입력값 산출 (단위 백만원)

| 공란 | 산식 | 값 | 구분 |
|---|---|---:|---|
| 학교용지부담금 | 아파트 분양수입 341,650.84 × 0.8% | 2,733.21 | 변동 |
| 분양대행수수료(아파트) | 300만원 × 612세대 | 1,836.00 | 변동 |
| 사업예비비 | 직접공사비 189,000 × 3% | 5,670.00 | 고정 |
| 중도금이자후불제 | 341,650.84 × 60% × 5.2% × 18/12 | 15,989.26 | 상쇄 |

| 앱 입력값 | 값 | 구성 |
|---|---:|---|
| 고정비 | 349,094.00 | 나머지 소요자금 (금융비용 30,259 · 사업예비비 · 시행사 대여금 상환 6,000 포함) |
| 변동비(100%) | 4,569.21 | 학교용지 0.8% + 분양대행 300만원/세대 — 분양률 비례 |
| 상쇄 항목 | 17,861.26 | 중도금이자후불제 15,989.26 + 이자상환적립계정 1,872 (01 Ⅲ-1) |
| 총사업비 | 353,663.21 | 고정 + 변동 |
| 총투자비 | 371,524.47 | 고정 + 변동 + 상쇄 = 소요자금 전 항목 합 |
| 기타유입 | 23,450 | 출자·대여 22,000 + 예치금 이자 1,450 (01 Ⅲ-2) |
| 후순위 | 48,000 | 유보금 42,000 (07 제9조) + 시행사 대여금 6,000 |

판단: 학교용지부담금은 「학교용지 확보 등에 관한 특례법」 제5조의2(공동주택 분양가격의 1천분의 8)에 따라 근생 제외. 포함 시 2,815.05.

## ③ 두 손익분기 (희망가 기준)

| | 기말현금 = 0 | 기말현금 = −48,000 (본PF 상환 한계) |
|---|---:|---:|
| 분양률 (평균 1,775.88만원/평) | 93.76% | 79.94% |
| 평당가 (분양률 100%) | 1,662.3만원 | 1,410.8만원 |

희망가·100% 기말현금 21,667.63 = 351,880.84 + 23,450 − 349,094 − 4,569.21. 적용가 기준 값은 공공데이터 조회 후 화면에서 계산됩니다.

## 구조


## 보안

- 인증키는 `.env.local` · Vercel 환경변수에만. `NEXT_PUBLIC_` 미사용, `server-only`로 호출부 격리.
- 브라우저는 지역명만 전송(한글·숫자·공백 40자 검증).
- `npm test` 보안 테스트: 공개 환경변수 사용 0건, 하드코딩 키 패턴 0건, 빌드 산출물 키 문자열 0건(키 설정 환경).
